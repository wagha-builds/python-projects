# 🖥️ Task Manager CLI App
---

## 💻 `README.md` for **Task Manager CLI App**



This is a simple **Command Line Task Manager (To-Do App)** built using **Python**.  
It allows you to manage your daily tasks directly from the terminal.

---

## 📖 Description

The CLI version allows users to:
- Add new todos
- View all existing todos
- Edit a todo
- Mark todos as completed
- Exit the program safely

All tasks are stored in `todos.txt` for persistence.

---

## 📂 Files Used

### **todolist_project.py**
This is the main program file that handles all terminal-based operations.
